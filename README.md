# SafeRide

A bilingual (Arabic/English) transportation-safety app in Flutter: light, dark
and system themes, Arabic (RTL) and English (LTR), local demo accounts, and a
journey dashboard — plan a journey, review it, and keep its history and
status on the phone. There is no backend yet; nothing is synced, shared or
tracked.

**Read `CLAUDE.md` first** — the project's structure, rules and decisions
live there.

```bash
flutter pub get
flutter run
```
