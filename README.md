# SafeRide

A bilingual (Arabic/English) transportation-safety app in Flutter: light, dark
and system themes, Arabic (RTL) and English (LTR), local demo accounts, a
journey dashboard (plan, review, edit, complete or cancel a journey and keep
its history), a Safety tab (trusted contacts, a safety guide, Saudi
emergency numbers) and a profile with language and appearance settings.
Everything is kept on the phone: there is no backend yet, and nothing is
synced, shared or tracked.

**Read `CLAUDE.md` first** — the project's structure, rules and decisions
live there. What is tested and what blocks a release is in
[`docs/PRODUCTION_READINESS.md`](docs/PRODUCTION_READINESS.md).

```bash
flutter pub get
flutter run
```
